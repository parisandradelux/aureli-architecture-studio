# AURELI — Architecture Studio

Independent architecture and interior design studio working across Europe and the Americas, specializing in residential, commercial, and hospitality projects. Its approach combines architecture, interior design, spatial design, and masterplanning to create thoughtful and purposeful spaces.

## Tech Stack

- Astro
- React
- TypeScript
- Tailwind CSS
- npm

## Commands

All commands are run from the project root directory:

| Command                   | Action                                             |
| :------------------------ | :------------------------------------------------- |
| `npm install`             | Install dependencies                               |
| `npm run dev`             | Start local development server at `localhost:4321` |
| `npm run build`           | Build the production site in `./dist/`             |
| `npm run preview`         | Preview the production build locally               |
| `npm run astro ...`       | Run Astro CLI commands                             |
| `npm run astro -- --help` | Display Astro CLI help                             |
